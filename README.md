# キャンドルノート — starter site

キャンドル専門メディアの静的サイト試作です。HTML/CSS/JavaScriptのみで構成しています。

## ファイル
- `index.html` — トップページと仮の記事カード
- `styles.css` — レスポンシブデザイン
- `script.js` — フッターの年表示

## 公開前に必ず変更すること
1. サイト名「キャンドルノート」が仮名であることを確認し、正式名称に変更する。
2. 「記事準備中」のカードを実際の記事ページへのリンクに置き換える。
3. `index.html` 内の `href="#"` を、公開したnote記事とAgrumerの販売先の実URLに変更する。
4. プロフィール、実績、制作写真を本人が確認し、事実に沿って更新する。
5. お問い合わせ先、プライバシーに関する案内、必要な運営者情報を整える。
6. Google Fontsは外部通信を行います。外部通信を避けたい場合はCSSの `@import` を削除してください。
7. 制作ノウハウや安全情報は、公開前に制作者本人が技術面を確認する。

## Cloudflare Pages への公開（静的HTML）
1. Cloudflareアカウントを用意する。
2. Cloudflare Dashboard で Workers & Pages / Pages の作成画面へ進む。
3. Git連携を選ぶ場合は、このフォルダをGitHubリポジトリに登録して接続する。ビルドコマンドは不要、出力ディレクトリはリポジトリのルート（`/`）にする。
4. 画面の案内に従ってデプロイし、発行されたURLを開いてスマートフォンでも確認する。

Cloudflareの画面名称や公開手順は変更される場合があります。画面に表示される最新の案内に従ってください。

## 注意
これは公開前の試作です。実際のnote、ショップ、記事ページへのリンクはまだ設定されていません。売上や検索流入を保証するものではありません。
